# Roadmap / 路线图

This is a direction for discussion, not a delivery schedule. Proposals are not implemented features.

以下是讨论方向，不是交付承诺；提议不代表已经实现。

## Available in the initial preview / 首版已有

- One Skill Library and explicit acquisition versus deployment.
- Claude Code / Codex global and project deployment on macOS.
- Import, update review, conflict inspection, explicit repair, and activity records.
- Guided migration with verified backups, resume, and restore.
- Device-local workspace and deployment metadata.

## Next areas to validate / 下一步验证方向

- Gather real-world migration and deployment feedback on both Mac architectures.
- Improve onboarding and explanations for conflicts and shared Skill edits.
- Add release signing and notarization when maintainer credentials are configured.
- Expand regression coverage around upstream integration and interrupted operations.

## Under consideration / 待讨论

- Additional Skill consumers, each with a verified path and compatibility contract.
- Windows and Linux support for the redesigned Skill model.
- More import sources and better discovery.

先收集两种 Mac 架构上的迁移与部署反馈，改进上手及冲突说明，并完善签名、公证与回归验证。更多工具、Windows/Linux 与导入来源仍需设计和验证。
