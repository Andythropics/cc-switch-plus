## 3.20.1-plus.2 — Skills workflow update / Skills 工作流更新

Based on CC Switch 3.20.1, including upstream work through `5a040348`.

- Adds external Skill source association and CLI installation synchronization.
- Presents available Skill updates in a review dialog.
- Unifies global and project Skill cards, clarifies deployment recovery actions, and highlights unavailable projects.
- Refactors application internals and fixes a Rust lint failure in deployment recovery.
- Replaces the README demo image with four app screenshots and recommends building locally from source in both languages.

新增外部 Skill 来源关联与 CLI 安装同步，集中审查可用更新；统一全局与项目技能卡片，明确部署修复操作并突出显示不可用项目。重构内部实现并修复 Rust 检查问题。中英文 README 更新为四张应用截图，并明确推荐本地源码构建使用。

**Preview:** macOS Apple Silicon and Intel; packages are not Apple Developer signed or notarized. Back up `~/.cc-switch/` and quit other CC Switch instances before upgrading.

### Installation / 安装

**Recommended: build and use locally from source. / 推荐在本地从源码构建并使用。**

Follow the [English build instructions](https://github.com/Andythropics/cc-switch-plus/tree/v3.20.1-plus.2#build-from-source) or [中文构建说明](https://github.com/Andythropics/cc-switch-plus/blob/v3.20.1-plus.2/README_ZH.md#从源码运行), then run `pnpm build`.

Prebuilt preview packages are also available: choose `macOS-aarch64` for Apple Silicon or `macOS-x86_64` for Intel. DMG and ZIP contain the same application. Verify downloads against `SHA256SUMS`.

也可下载预览安装包：Apple Silicon 选择 `macOS-aarch64`，Intel 选择 `macOS-x86_64`。DMG 和 ZIP 包含同一应用，请核对 `SHA256SUMS`。

Requires macOS 12+. Packages are not Apple Developer signed or notarized. After verifying the download, use System Settings → Privacy & Security → Open Anyway if needed. Plus shares `~/.cc-switch/` with CC Switch; quit other instances and back up this directory before upgrading. Application updates remain manual.

需要 macOS 12+，安装包尚未使用 Apple 开发者证书签名或公证；核验后可按需使用系统「仍要打开」。升级前请退出其他 CC Switch 实例并备份共享的 `~/.cc-switch/` 数据目录。应用仍通过手动更新。
