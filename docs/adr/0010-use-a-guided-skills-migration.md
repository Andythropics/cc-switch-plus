# Use a Guided Skills Migration

On macOS the legacy-to-redesigned Skills migration begins only when the user first opens the new Skills management page. A preflight view inventories managed and unmanaged content, explains planned moves and links, and backs up the database and affected managed directories before applying changes. The user may defer migration, in which case the new page remains read-only; Windows and Linux never run this migration. Migration progress is journaled and resumable instead of being hidden in application startup.
