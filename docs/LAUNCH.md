# Launch copy / 发布文案

## 中文

**CC Switch Plus 开源了：一个 Skill 库，连接 Claude Code、Codex 和每个项目。**

我基于 CC Switch 做了一个 Skill 管理增强版：集中维护技能库，再按工具和项目部署；通过链接共享同一份内容，并提供兼容性检查、更新前本地修改审查、部署异常处理、迁移备份与操作记录。

首个预览版支持 macOS 上的 Claude Code 和 Codex，使用 MIT 协议。欢迎试用、反馈，也欢迎分享你希望怎样管理自己的 Skills。

仓库：https://github.com/Andythropics/cc-switch-plus
下载：https://github.com/Andythropics/cc-switch-plus/releases

已有 CC Switch 用户请先备份数据、退出原版并阅读迁移说明。预览包尚未完成 Apple 开发者签名或公证。

## English

**CC Switch Plus is open source: one Skill library for Claude Code, Codex, and every project.**

Built on CC Switch, Plus centralizes your Skills and deploys them per tool and workspace. Managed links share one source, with compatibility checks, local-edit review before updates, deployment inspection, migration backups, and activity history.

The first MIT-licensed preview supports Claude Code and Codex on macOS. Try it, report what you find, and share the workflows you want to manage.

Repository: https://github.com/Andythropics/cc-switch-plus
Downloads: https://github.com/Andythropics/cc-switch-plus/releases

Existing CC Switch users should back up their data, quit the original app, and read the migration guide. Preview packages are not Apple Developer signed or notarized.
