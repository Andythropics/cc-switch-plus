# Code of Conduct / 行为准则

We welcome contributors regardless of background, identity, experience, or language. Be respectful, assume good intent where reasonable, give specific technical feedback, and accept correction.

欢迎不同背景、身份、经验和语言的贡献者。请尊重他人，提出具体的技术反馈，并愿意接受纠正。

Harassment, threats, discriminatory remarks, sexualized conduct, impersonation, publishing private information, and repeated disruptive behavior are unacceptable in issues, pull requests, discussions, and other project spaces.

禁止骚扰、威胁、歧视、性骚扰、冒充身份、泄露私人信息和反复干扰社区。以上要求适用于 Issue、PR、讨论区等项目空间。

Maintainers may edit or remove harmful content, lock conversations, or restrict participation. Responses should be proportionate to the behavior and protect affected participants.

维护者可编辑或移除有害内容、锁定讨论或限制参与。处理应与行为程度相称，并保护受到影响的人。

For a public incident, use GitHub's report-content controls to alert repository administrators. For private or platform-wide abuse, use [GitHub Support](https://support.github.com/contact/report-abuse). Do not disclose personal details in a public report. Security vulnerabilities use the separate [Security Policy](SECURITY.md).

公开事件可使用 GitHub 内容举报功能通知仓库管理者；私密或跨平台滥用可通过 [GitHub Support](https://support.github.com/contact/report-abuse) 报告。不要在公开报告中披露个人隐私。安全漏洞请使用独立的[安全策略](SECURITY.md)入口。
